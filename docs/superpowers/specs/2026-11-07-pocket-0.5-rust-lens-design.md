# Pocket 0.5 — Rust Lens

## Цель

Обновить визуал и добавить в чат инструменты для автономной работы, не меняя
протокол агента, системный промпт, встроенный сервер и существующие потоки.
Rust используется там, где он реально даёт выигрыш: обход workspace, diff и
подсветка кода.

## Что меняется для пользователя

1. **`@`-файлы в композере.** При вводе `@` появляется список файлов рабочего
   каталога. Выбранный путь вставляется в задание как `@path`. Агент читает
   файл сам — протокол prompt не меняется.
2. **Diff-карточки правок.** Для `edit`/`multiedit`/`apply_patch` вместо
   сырого JSON показывается компактный diff: номера строк, `+`/`−`, статистика.
   Свёрнут после завершения, развёрнут во время выполнения.
3. **Итог хода.** В конце ответа агента — карточка: инструменты, файлы,
   команды, ошибки, токены и стоимость сессии, кнопка «копировать».
4. **Подсветка кода.** Fenced-блоки и diff подсвечиваются через Rust
   (`syntect`), с откатом к текущему монохромному виду.
5. **Визуальный рефреш.** Более глубокая фиолетовая палитра, градиентный фон
   чата, обновлённые пузыри, композер, док, пустое состояние и анимации.

## Архитектура

- `rust/pocket-rs` — отдельный бинарник без JNI. Собирается нативным
  Termux `rustc` (`aarch64-linux-android`), упаковывается как
  `app/src/main/tools/arm64-v8a/libpocket_rs.so` и запускается через symlink
  `pocket-rs` из `files/opencode/tools` — та же проверенная схема, что у `rg`.
- Команды: `find`, `diff`, `highlight`, `version`. Ввод/вывод — JSON,
  `diff`/`highlight` читают stdin.
- Kotlin: `RustTools` (запуск, таймауты, LRU-кэш), чистые парсеры
  (`EditPatch`, `RustDiff`, `MentionQuery`, `TurnStats`) — покрыты JVM-тестами.
- Любой сбой Rust не ломает чат: UI откатывается к прежнему поведению.

## Безопасность и границы

- Rust-команды только читают файлы; ничего не пишут и не меняют.
- Лимиты: 200k файлов в индексе, 6k строк diff, 4k строк/256 KB подсветки,
  таймауты 3–6 с, обязательное уничтожение процесса.
- Не меняются: `api.prompt`, события сессии, системный промпт, набор скилов,
  конфиг `opencode.json`, MCP, сервер, debug bridge.
- APK: +1 бинарник, версия 0.5.0 (code 5).

## Проверка

- `cargo test` для Rust, JVM unit-тесты для парсеров и summary.
- Сборка на удалённом сервере, установка APK, проверка `/state`,
  `pocket-rs version/find/diff/highlight` на устройстве, повторная проверка
  `rg`, vision-вложений и MCP.
- 16 KB alignment: `readelf -l` → `Align 0x4000`.
