# OpenCode Pocket 0.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Выпустить 0.3.0: плавающий док с современными иконками, встроенные 42 скила и скрытый loopback-канал отладки с журналом ошибок.

**Architecture:** Скилы лежат в assets и досеваются в XDG-конфиг до старта сервера. Отладка — singleton-журнал + HTTP на loopback с токеном, состояние отдаёт ViewModel через провайдер. UI перестраивается с `Scaffold` на `Box`: док — отдельный слой, IME обрабатывает только композер.

**Tech Stack:** Kotlin, Jetpack Compose Material3, `androidx.compose.material:material-icons-extended`, `ServerSocket`, `org.json`, JUnit.

**Spec:** `docs/superpowers/specs/2026-11-06-pocket-0.3-design.md`

## Global Constraints

- `minSdk 26`, `targetSdk 35`, `compileSdk 35`, arm64-v8a, `com.pocket.opencode`.
- OpenCode `v2.1.4-beta.4b83402a`, версия приложения `0.3.0` / `versionCode 3`.
- Отладочный мост слушает только `127.0.0.1`; без токена — 401.
- Скилы не перезаписывают существующие файлы.
- В журнал не попадают пароли, ключи и токен.

## Review Focus

- Клавиатура: док не должен уезжать вместе с IME, поле ввода — должно.
- Поворот и возврат из фона: вкладка, черновик и док остаются на месте.
- Скилы: повторный старт не плодит дубликаты и не затирает правки.
- Отладка: запрос без токена и с чужим токеном не выполняет действий.
- Журнал: ротация не теряет последние события и не растёт бесконечно.
